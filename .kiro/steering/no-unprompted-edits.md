# No unprompted file edits

- NEVER make code changes, file edits, or file creation without explicit permission from the user.
- When the user asks a question, answer the question. Questions do not imply a request to change code.
- Only perform file modifications when the user explicitly asks you to implement, fix, write, create, or change something.
- If you believe a code change would be helpful, describe what you would do and ask for permission first.
